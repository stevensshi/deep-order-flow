# Protocols

Edited copies of the four pre-registration documents of the experiments in `results/` (the earlier stage, spec
`earlier`, had none). Each document was written before the experiment it describes. The copies replace internal
file paths, internal names and process wording with neutral words; no rule, split, model, setting, date or number is
changed. The experiment specs
(`src/dof/experiments/specs/__init__.py`) and the stored result records pin the sha256 of each original; the note
at the top of each copy gives that hash and the sha256 of the copy's own text below the note.
